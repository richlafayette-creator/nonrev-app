# Itinerary Integrity Is Sacred

Displayed itineraries must be 100% accurate representations of the generated route framework.

- Never omit legs.
- Never substitute hubs for origins.
- Never fabricate connections.
- Never display stale or historical rows as current live availability.
- If certainty is low, show less information, not incorrect information.
- Trust always overrides aesthetics and feature completeness.
